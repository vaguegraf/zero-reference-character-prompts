# Zero-Reference AI Character Prompts

A curated prompt engineering library designed to maintain **strict character identity, outfit details, lighting, and environment consistency** across multiple camera angles and aspect ratios (`16:9`, `1:1`, `9:16`) using **pure text architecture**—without `--cref` image prompts, FaceSwap, ControlNet, or custom LoRAs.

Tested and optimized for **Midjourney v6.1**, **Flux.1**, and **SDXL / SD3**.

## Character Catalog

### Sports & Outdoors
* **[Ingrid Solberg — Golden Hour Clay Tennis](sports-and-outdoors/ingrid-solberg-tennis.md)** — Three-shot editorial storyboard (`16:9` wide, `1:1` high-angle, `9:16` low-angle) on a terracotta clay court.

## How to Use

Open any character file, click the copy button on the desired aspect ratio prompt (`16:9`, `1:1`, or `9:16`), and paste it directly into your image generator. No reference images are required.
